06
Vendo a modelagem funcionar em Java
O exemplo reúne uma classe Equipamento, dois objetos e uma locação de três dias. É um programa Java executável.
O que observar no programa
  1. class Equipamento define o modelo.
  2. new Equipamento(...) cria objetos diferentes.
  3. projetor.alugar() executa um método.
  4. Locacao liga cliente, equipamento e número de dias.
  5. calcularValor() multiplica diária pelos dias.
Para testar, copie o código, abra o OneCompiler Java, substitua o conteúdo do editor e clique em Run.

Main.java • programa completo
class Cliente {
    String nome;

    Cliente(String nome) {
        this.nome = nome;
    }
}

class Equipamento {
    String codigo;
    String descricao;
    double valorDiaria;
    boolean disponivel;

    Equipamento(String codigo, String descricao, double valorDiaria) {
        this.codigo = codigo;
        this.descricao = descricao;
        this.valorDiaria = valorDiaria;
        this.disponivel = true;
    }

    boolean alugar() {
        if (!disponivel) return false;
        disponivel = false;
        return true;
    }

    void devolver() {
        disponivel = true;
    }
}

class Locacao {
    Cliente cliente;
    Equipamento equipamento;
    int dias;

    Locacao(Cliente cliente, Equipamento equipamento, int dias) {
        this.cliente = cliente;
        this.equipamento = equipamento;
        this.dias = dias;
    }

    double calcularValor() {
        return equipamento.valorDiaria * dias;
    }
}

public class Main {
    public static void main(String[] args) {
        Cliente ana = new Cliente("Ana Souza");
        Equipamento projetor = new Equipamento("EQ-101", "Projetor LED", 80.0);
        Equipamento notebook = new Equipamento("EQ-102", "Notebook Dell", 120.0);
        Locacao locacao = new Locacao(ana, projetor, 3);

        System.out.println("Cliente: " + ana.nome);
        System.out.println("Equipamento: " + projetor.descricao);
        System.out.printf("Diária: R$ %.2f%n", projetor.valorDiaria);
        System.out.println("Dias: " + locacao.dias);
        System.out.printf("Valor previsto: R$ %.2f%n", locacao.calcularValor());
        projetor.alugar();
        System.out.println("Status após alugar: " + (projetor.disponivel ? "disponível" : "alugado"));
        projetor.devolver();
        System.out.println("Status após devolver: " + (projetor.disponivel ? "disponível" : "alugado"));
    }
}
Por onde seguir: mude no Java o valor da diária para 90 e o período para 4 dias. Execute novamente e compare o resultado. Se o sistema estiver correto, o total será R$ 360,00.
