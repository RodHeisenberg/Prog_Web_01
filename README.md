# Fundamentos de Programação Orientada a Objetos

**Material autoral do Professor Rodrigo Moreira. Todos os direitos reservados.**

Este repositório reúne explicações, demonstrações e uma atividade prática sobre **paradigmas de programação, classes, objetos, atributos, métodos, abstração e modelagem de classes em Java**. O estudo utiliza do início ao fim uma situação fictícia de locação de equipamentos, a **LocaFácil**.

## Como estudar

1. Abra `index.html` ou acesse o endereço do GitHub Pages do repositório. Leia os conceitos e consulte os recursos externos disponíveis na seção Ferramentas e leituras.
2. Acesse `laboratorio.html`. Acompanhe as simulações de identificação de entidades, criação de objetos, alteração de estado, abstração e modelagem de classes.
3. No laboratório, copie o código Java completo ou use `exemplos/Main.java`. Abra [OneCompiler Java](https://onecompiler.org/java), cole o código e execute. Troque os valores da diária e o número de dias para observar novos resultados.
4. Ao final, abra `atividade.html`. Resolva os 20 desafios práticos, confira as respostas e crie sua própria locação. Salve o arquivo `.txt` com sua resolução, se solicitado pelo professor.

## Arquivos do projeto

- `index.html`: conteúdo de referência e recursos de estudo.
- `laboratorio.html`: simulações guiadas do cenário LocaFácil.
- `atividade.html`: atividades práticas com conferência e projeto final.
- `assets/css/style.css`: visual responsivo.
- `assets/js`: interações locais das páginas.
- `exemplos/Main.java`: programa Java de demonstração.
