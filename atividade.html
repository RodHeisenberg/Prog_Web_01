Mesmo cenário do laboratório

O atendimento de Ana Souza

Uma locação deve relacionar a cliente Ana, o Projetor LED (EQ-101), uma diária de R$ 80,00 e um prazo de três dias. O sistema precisa identificar classes, representar objetos, realizar ações e calcular o valor previsto.

Critérios da atividade

Identificar entidades, definir atributos e métodos, montar código Java inicial e demonstrar uma locação funcional.

Etapa A

Entender o cenário e identificar as classes

Escreva respostas curtas, sempre pensando nas entidades da locadora.

Etapa B

Definir atributos e métodos

Use nomes coerentes com a classe Equipamento. Preferimos os identificadores usados na explicação.

Etapa C

Escrever a estrutura da classe em Java

Complete as declarações e operações. Observe ponto e vírgula, chaves e nomes dos campos.

Etapa D

Criar objetos e executar comportamentos

Reproduza partes do fluxo que foi mostrado no laboratório, agora escrevendo o código.

Desafio de aplicação

Monte sua própria locação

Preencha os dados, simule uma operação e compare o total obtido com o código Java que foi demonstrado. Esta etapa é uma aplicação do modelo e não apenas uma pergunta.
